## characters/ — AI 직원 캐릭터

ToxSam CC0 컬렉션에 본격적인 캐릭터 모델 없음.
기존 Assets/ThirdParty/Robots/ + Assets/Project/Robots/ 재사용.
추가 캐릭터 필요시 Mixamo (무료 리깅+애니메이션) 권장.

## Import to Unity

glTFast 패키지(com.unity.cloud.gltfast)가 이미 설치되어 있어 GLB 직접 임포트 가능.
unity-mcp 연결 후 에디터에서 씬에 배치 가능.
