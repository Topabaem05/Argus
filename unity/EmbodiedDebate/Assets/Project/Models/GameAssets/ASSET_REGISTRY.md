# AI Company Game Asset Registry

This file is the release gate for third-party visual/audio assets. A file being downloadable or present in the repository is not sufficient; its source, author and redistribution terms must be recorded here.

## License states

- **VERIFIED** — source and license are documented; allowed in builds.
- **PROTOTYPE_ONLY** — usable for local development, but provenance is incomplete.
- **PLANNED** — not imported.
- **REPLACE** — temporary primitive or placeholder.

## Important release block

The current `KayKit` directory contains many useful prototype objects but no adjacent attribution/license record was found. Before a public or commercial build, do one of the following:

1. add the exact original pack URL, author, version and license text;
2. replace the used objects with verified CC0 assets;
3. replace them with original Argus meshes.

The scene has primitive fallbacks, so gameplay does not need to block on this cleanup.

## Asset intake checklist

Every imported external pack must include:

- exact source URL and download date;
- author/organization;
- pack/version name;
- full license text or immutable license URL;
- attribution wording when required;
- list of imported files (do not dump entire packs by default);
- texture/material dependencies;
- approximate disk size and triangle count;
- Unity import settings and scale convention;
- proof that redistribution inside a game build is allowed.

Preferred order:

1. CC0/public-domain-like assets;
2. permissive attribution licenses with a clear NOTICE entry;
3. purchased Unity Asset Store content kept outside public source control when redistribution terms require it.

Do not import assets with non-commercial, no-derivatives, unclear AI-generated provenance, extracted-game, fan-art or brand/IP restrictions.

## Style constraints

- rounded, chunky, toy-like forms;
- simple material blocks rather than photo textures;
- pastel company color variants;
- strong silhouettes at an orthographic quarter view;
- no tiny details that disappear at the default camera zoom;
- consistent real-world scale: one minibot approximately 1.4–1.7 Unity units tall.
